# 우리집 환경 대시보드

온도, 습도, 조도, 적외선 장애물, 고감도 소리 센서를 위한 반응형 웹 대시보드입니다. 현재는 데모 값이 3초마다 갱신됩니다. 조도·적외선·소리 센서는 외출 중 출입 흔적과 발생 시간을 추정하며 사람의 신원을 식별하지는 않습니다.

## 실행

- Windows: `index.html`을 더블클릭합니다.
- 같은 Wi-Fi의 모바일에서 보기: 이 폴더에서 `python -m http.server 8000`을 실행한 뒤 모바일 브라우저에서 `http://컴퓨터IP:8000`으로 접속합니다.

아두이노 연결 시 `app.js`의 `updateSensors()`를 시리얼/API 수신 코드로 교체할 수 있습니다.
